VSRG Skin Converter — Windows x64 Portable
===========================================

Requirements
------------
Windows 10 or newer on an x64 processor. Node.js and npm are included; do not install them.

Run
---
1. Extract the complete ZIP to a writable folder. Do not run it inside the ZIP viewer.
2. Double-click vsrg-skin-converter.cmd, or open a terminal in the extracted folder and run it.
3. Select the source game and the requested game folders when prompted.

Metadata commands
-----------------
vsrg-skin-converter.cmd --help
vsrg-skin-converter.cmd --version

Keep runtime, node_modules, and templates next to the launcher. Moving individual files breaks
the portable application. This build is not code-signed, has no installer, and does not update
itself automatically. Download future versions manually from the project's official source.
